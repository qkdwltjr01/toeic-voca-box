# 토익 단어 상자

토익 단어를 간격 반복(Leitner)으로 외우는 오프라인 웹앱. 폰 우선.

## 쓰는 법

`voca-box.html` 을 더블클릭. 끝. 인터넷 없이도 돌아가고, 단어 데이터까지 파일 하나에 다 들어있다.

## 동기화

학습 기록은 기본적으로 그 브라우저의 localStorage에만 있다. 그래서 크롬에서 등록한 단어가
엣지에는 없고, 브라우저 데이터를 지우면 날아간다. 설정 → **클라우드 동기화** 를 연결하면
기록이 본인 GitHub 계정의 **비공개 Gist** 한 개(`voca-box-state.json`)에 올라가고,
같은 토큰을 넣은 모든 기기가 같은 기록을 쓴다.

토큰 발급: GitHub → Settings → Developer settings → Personal access tokens →
**Tokens (classic)** → Generate new token → 권한은 **gist** 하나만 체크.
이 토큰으로는 Gist 외에 아무것도 못 건드리고, 토큰 자체는 브라우저에만 남고 Gist에는 올라가지 않는다.

두 번째 기기에서는 같은 토큰만 넣으면 된다 — 기존 Gist를 찾아서 알아서 붙는다.

**병합 규칙.** 두 기기에서 각자 공부했을 수 있으므로 통째로 덮어쓰지 않는다.

| 대상 | 규칙 |
|---|---|
| 카드 진도 | 단어마다 마지막으로 채점한 시각(`ts`)이 더 최근인 쪽 |
| 내 단어 | 단어마다 `ts`가 더 최근인 쪽. 지운 기록(묘비)이 더 최근이면 되살리지 않는다 |
| 일별 기록 | 같은 날짜는 항목별 최댓값 (더하면 재동기화마다 불어난다) |
| 설정 | 통째로 최근에 저장된 쪽 |

병합은 순서를 바꿔도, 여러 번 돌려도 결과가 같다. 다만 **두 기기에서 정확히 동시에**
동기화가 겹치면 늦게 올라간 쪽이 이긴다 — Gist에는 조건부 쓰기가 없다. 한 기기씩 쓰면 문제없다.

동기화를 켜도 로컬 저장은 그대로 쓴다. 비행기모드에서도 평소처럼 공부하고,
연결이 돌아오면 밀려 있던 변경이 자동으로 올라간다.

파일 백업(설정 → 파일 백업)은 그대로 남아 있다. 통째로 옮기거나 보관할 때 쓴다.

## 폰에서 쓰기

저장소가 private이라 무료 GitHub Pages는 못 쓴다. **Cloudflare Pages** 가 private 레포를
그대로 무료 배포해 준다:

1. dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git
2. 이 저장소 선택. 빌드 명령 없음, 출력 디렉터리는 `/` (루트)
3. 배포되면 `https://<프로젝트명>.pages.dev` 로 폰에서도 열린다

주소를 아무나 못 열게 하려면 Cloudflare Access로 잠그면 된다(무료 한도 안).
호스팅 없이 각 기기에 HTML 파일을 두고 써도 동기화는 똑같이 된다 —
GitHub API가 `file://` 요청도 받아 준다.

## 파일

| 파일 | 설명 |
|---|---|
| `voca-box.html` | 앱 본체. CSS·JS·단어 데이터가 전부 인라인된 단일 파일 |
| `words.json` | PDF에서 추출한 2,109단어 |
| `build.py` | PDF → `words.json` → HTML 주입까지 한 번에 |

원본 PDF는 용량이 커서 git에 넣지 않았다(`.gitignore`). 다시 파싱하려면
`토익-단어장-PDF-for-PC-A4size-All.pdf` 를 이 폴더에 두고 실행:

```
pip install pymupdf
python build.py
```

`build.py` 는 추출 후 빠진 번호·중복·괄호 짝·품사 누락을 스스로 검사해서 보고한다.

## 단어 데이터

출처: 토익 독종반 단어장 PDF (중요도 순 2,109단어). 단어 + 뜻(최대 2개)만 있고
예문·동의어·파생어는 없다 — 그건 사이트 개별 페이지에만 있는데 크롤링이 막혀 있다.

PDF 표가 세로 중앙정렬이라 여러 줄짜리 뜻의 첫 줄이 윗 행으로 넘어가는 문제가 있었다.
품사 마커가 셀 정중앙에 온다는 점을 기준점으로 삼아 해결했다 (`build.py` 참고).

## 앱 구조

- **간격 반복**: Leitner 5단계. 맞히면 한 칸 위, 틀리면 1단계로. 처음 본 단어를
  바로 맞히면 2단계로 건너뛴다(이미 아는 단어가 매일 복습 자리를 먹지 않도록).
- **복습 간격이 시험일에 맞춰 압축된다**. 30일+ 는 `1·3·7·16·35일`,
  2주 남았으면 `1·2·4·7·11일`. 안 그러면 35일짜리가 시험 뒤에나 돌아온다.
- **모드**: 플래시카드 / 4지선다 / 스펠링. 자동 모드는 단어의 상자 단계에 따라 난이도를 올린다.
  4지선다 오답 보기는 같은 품사에서 뽑는다(품사만 보고 찍는 걸 막기 위해).
- **채점 정정**: 답을 본 뒤 "사실 몰랐어요" / "찍었어요" / "알고 있었어요"로 뒤집을 수 있다.
  플래시카드는 답을 보기 전에 스스로 매기므로 필수.
- **하루치 쪼개기**: 하루 목표를 `한 번에 풀 개수`(기본 25) 단위로 잘라서 낸다.
- **내 단어**: 경선식 등 다른 책 단어를 연상 문구와 함께 등록. 철자가 겹치면 새 카드를
  만들지 않고 기존 단어에 연상·뜻을 붙인다. 등록한 단어는 새 단어 큐 맨 앞에 온다.
